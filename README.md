# Dr. Emmanuel Carlos de Souza

Site institucional de advocacia com sede em Itabira, Minas Gerais. Identidade em dourado, prata, grafite e marfim, com as fotografias reais fornecidas pelo cliente.

## Desenvolvimento

- Instalar: `npm install`
- Iniciar: `npm run dev`
- Validar: `npm run lint` e `npm run build`

Next.js 16 App Router, React 19, Tailwind CSS 4 e Framer Motion. A arquitetura e os mecanismos de animação do template foram preservados. O tema do Tailwind 4 fica em `app/globals.css`, com `@theme inline`.

## Imagens e identidade

Logo original preservado em `public/emmanuel-logo-original.png`. A versão `public/emmanuel-logo.png` foi preparada com ImageGen para remover o fundo quadriculado gravado no arquivo. As duas fotografias foram convertidas em WebP, com largura máxima de 1200px e sem recortes permanentes: `emmanuel-hero.webp` e `emmanuel-retrato.webp`. As imagens usam `next/image`, tamanhos responsivos, preload da imagem principal e carregamento tardio das demais. Não há fotografia de escritório; a seção da sede apresenta o endereço real.

Paleta derivada da amostragem dos tons dourados e prateados do logo: dourado #c79559, dourado claro #ffe2a6, prata #d8d9dc. Tons de apoio: grafite #17191c, marfim #f8f6f1 e dourado escuro #79522d, utilizado para contraste em superfícies claras. Cormorant Garamond nos títulos e Plus Jakarta Sans nos textos.
